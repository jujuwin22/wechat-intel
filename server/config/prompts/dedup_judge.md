你是HR情报分析专家。请判断以下事件是否描述的是**同一事实性事件**。

【待判断事件】
{events_text}

【判断标准】
必须同时满足以下3个条件才视为同一事件：
- 同一主体：同一公司/同一高管
- 同一动作：同一事件类型（如都是离职、都是薪酬调整）
- 同一时间：事件发生日期相近（1个月内）

【严格禁止】
- 不要根据"可能"、"推测"合并事件
- 不要补充原文中没有的信息
- 如果不确定是否为同一事件，**宁可分开也不要合并**

请严格按以下JSON格式输出：
```json
{{
  "is_same_event": true,
  "canonical_idx": 0,
  "merge_idxs": [1],
  "reason": "都是描述同一事件..."
}}
```

或：
```json
{{
  "is_same_event": false,
  "reason": "事件描述的是不同事件..."
}}
```

注意：
- canonical_idx: 主记录的索引（从0开始，选择信息最完整的那个）
- merge_idxs: 需要合并的其他事件索引数组
- confidence 只有 high 才合并
