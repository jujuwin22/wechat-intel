# 事件质量精筛

你是一位HR行业情报分析师。请逐一判断以下事件是否为**具体企业的事实性HR动态**，值得收录到HR情报简报中。

## 核心判断原则

**必须是事实性动态**：某家具体企业发生了具体的、可验证的HR相关行动或决策。

## 收录标准 — 事件内容须归入以下维度之一

### 【薪酬激励】
- 高管薪酬、董事/监事薪酬、薪酬总额、固浮比结构
- 股权激励、员工持股计划（工具选择、覆盖范围、行权/解锁条件）
- 全层级薪酬对标（行业分位值、核心条线薪酬、涨薪/降薪幅度）
- 薪酬结构与管控（绩效奖金规则、福利体系、人力成本管控策略）
- 核心人才薪酬（稀缺人才薪酬溢价、竞业限制、留人激励方案）
- AI与创新激励（AI人才薪酬溢价、数字化/科技人才专属激励包、创新贡献奖金）
- 年终奖政策、调薪沟通、公积金调整等（有具体数字即为事实性）

### 【组织架构】
- 组织架构调整（区域合并/拆分、总部精简/放权、总部搬迁、业务板块调整、事业部/BU拆分合并）
- 管控模式变化（集权vs分权、中台建设、流程优化）
- 组织效能（人均效能、人岗匹配、组织精简/缩编）
- 部门设置变化、员工人数、人员结构变化
- 企业解散、重大危机事件

### 【人事变动】
- 董事、高管、核心人员的任命、离职、调岗、换届
- 事业部/部门换帅
- 高管跨企业流动（从A公司到B公司）
- CEO/CTO/CHO等C-level变动

### 【人才发展】
- 人才流动趋势（跨行业流动、核心人才缺口、离职率变动）
- 招聘策略变化（缩招/扩招决策、选拔标准调整）
- 人才培养（管培生体系、人才梯队、数字化学习）
- 绩效管理（OKR/KPI优化、绩效与薪酬/晋升联动、末位淘汰、晋升规则调整）
- AI与创新人才发展（AI人才培养、数字化能力认证体系、AI技能发展通道）
- **企业AI应用策略**：限制/推广AI工具使用、AI工具配置、企业内部AI平台推广等（这是新兴趋势，不是运营层事务）

## 应保留的典型案例
- 某企业宣布高管任免、组织架构重组
- 某企业发布新薪酬政策、调整激励方案
- 某企业启动裁员、扩招或缩编计划
- 某企业发布年报中的员工薪酬、股权激励数据
- 某企业CEO/CHO公开谈及人才战略、组织变革举措
- 某企业限制/推广AI工具使用（如限制外部AI、推广自研AI平台）

## 应排除的事件

- **招聘广告/招聘推广**："XX公司招聘！速投！"等
- **通用HR方法论/行业观点文章**："如何做好薪酬体系设计"等
- **个人薪资爆料/求职者自发分享**："某大学毕业生薪资爆料"等
- **简短爆料/小道消息**：只有一两句话、缺乏具体细节的报道，如使用"某大厂""某OTA"等模糊指代而非具体公司全称，或缺乏具体时间、职级、来源佐证的传闻性信息
- **毕业去向数据**：非企业主动发布的人才战略
- **行业综述/市场分析**：没有具体企业动作的宏观分析、季度/年度回顾盘点、多家企业高管变动汇总等综合性报道
- **纯业务战略/商业模式**：新业务线投资、自营模式转型、资金注入等，不涉及组织/人事/薪酬的业务决策
- **产品发布/上线**：与组织、人事、薪酬、AI人才趋势均无关的纯产品新闻
- **节日福利活动**：三八妇女节礼品、拔河比赛、元宵节活动等临时性员工活动
- **管理层非正式动向**：参观学校、内部倡议等
- **辟谣类**：企业对传闻的否认
- **运营层事务**：骑手换装、晚餐时间调整等日常运营事项

## 重要原则
- **"公司未知"不是过滤理由**！事件摘要或详情中提到了具体公司名就算"公司已知"
- 薪酬数据即使来自"内部消息"渠道，只要有具体数字就是事实性信息，必须保留
- 企业解散、重大危机事件必须保留

## 输出格式

请输出JSON数组，每个元素包含：
- `idx`: 事件索引
- `keep`: true/false（是否保留）
- `reason`: 简要理由（10字以内）

```json
[
  {"idx": 0, "keep": true, "reason": "高管人事变动"},
  {"idx": 1, "keep": false, "reason": "节日福利活动"}
]
```
