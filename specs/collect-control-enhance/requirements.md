# 需求文档: 采集控制增强（水位线管理 + 公众号选择采集）

## 1. 介绍
在前端采集控制页面（CollectView.vue）新增两项功能：手动管理水位线和选择性采集公众号，提升采集调试效率。

## 2. 需求与用户故事

### 需求 1: 水位线管理
**用户故事:** As a 情报分析师, I want 在前端查看和管理所有公众号的水位线, so that 我可以灵活控制重新采集的范围。

#### 验收标准
* **WHEN** 用户打开采集控制页面, **THEN** 系统 **SHALL** 显示所有公众号的水位线信息（公众号名称 + 最后采集时间）。
* **WHEN** 用户点击某个公众号旁的"清除"按钮, **THEN** 系统 **SHALL** 清除该公众号的水位线，下次采集时重新拉取全部文章。
* **WHEN** 用户点击"清除全部水位线"按钮, **THEN** 系统 **SHALL** 清除所有公众号的水位线。
* **IF** 清除操作成功, **THEN** 系统 **SHALL** 立即刷新水位线列表显示。

---

### 需求 2: 选择公众号采集
**用户故事:** As a 情报分析师, I want 勾选要采集的公众号再启动采集, so that 我可以只采集特定公众号而不必每次全量采集。

#### 验收标准
* **WHEN** 用户打开采集控制页面, **THEN** 系统 **SHALL** 显示所有已配置公众号的列表，每个公众号前有勾选框，默认全选。
* **WHEN** 用户勾选部分公众号后点击"开始采集", **THEN** 系统 **SHALL** 仅采集被勾选的公众号。
* **WHEN** 用户未勾选任何公众号时点击"开始采集", **THEN** 系统 **SHALL** 提示"请至少选择一个公众号"。
* **WHEN** 采集正在进行中, **THEN** 系统 **SHALL** 禁用公众号勾选和开始按钮，防止重复触发。
