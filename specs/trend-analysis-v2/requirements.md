# 需求文档: 趋势分析优化 V2

## 1. 介绍

优化 HR 情报趋势分析的提炼质量，使其从"事件分组罗列"升级为"战略洞察提炼"，服务于 CHO/HRD 团队的决策参考和管理层月度汇报。

## 2. 需求与用户故事

### 需求 1: 趋势提炼质量提升

**用户故事:** As a CHO/HRBP，I want 从月度HR事件中看到高质量的趋势洞察，so that 我能快速理解外部市场HR动态的核心方向，辅助战略决策。

#### 验收标准

* **WHEN** pipeline 完成事件去重后生成趋势报告，**THEN** 系统 **SHALL** 提炼出高质量的趋势洞察，每条趋势需反映多个事件背后的共同战略方向。
* **WHEN** 趋势提炼完成，**THEN** 趋势标题 **SHALL** 体现战略视角而非简单分类，参考方向如：
  - 激励管理机制优化
  - 组织架构调整聚焦协同赋能
  - 价值评估体系变革
  - 组织提效
  - AI策略
  - 员工激励
* **IF** 某些事件无法归入任何有意义的趋势，**THEN** 系统 **SHALL** 将其保留在"其他动态"中，不强行归类。
* **WHEN** LLM 提炼趋势时，**THEN** 趋势数量 **SHALL** 由 LLM 根据事件内容自行判断（不设固定数量），但每条趋势至少关联 2 个事件。

---

### 需求 2: 趋势报告增加"对我们意味着什么"视角

**用户故事:** As a CHO，I want 每条趋势都有"对龙湖意味着什么"的分析，so that 我能直接从报告中获得可行动的参考建议。

#### 验收标准

* **WHEN** 每条趋势生成后，**THEN** 系统 **SHALL** 附带一段"启示与建议"（implications），从龙湖集团/地产行业HR视角分析该趋势的影响和可参考的行动方向。
* **IF** 趋势主要涉及互联网公司，**THEN** 启示 **SHALL** 聚焦于"哪些做法可借鉴到地产行业"。
* **IF** 趋势涉及地产同行，**THEN** 启示 **SHALL** 聚焦于"对标分析：我们的差距或优势"。

---

### 需求 3: 趋势报告结构优化

**用户故事:** As a 管理层读者，I want 趋势报告结构清晰、层次分明，so that 我能在3分钟内抓住本月核心要点。

#### 验收标准

* **WHEN** 趋势报告生成，**THEN** 报告 **SHALL** 包含以下结构：
  1. **执行摘要**（Executive Summary）：2-3句话概括本月最重要的趋势方向
  2. **核心趋势**：每条趋势含标题、摘要、启示建议、关联事件
  3. **其他动态**：未归类但值得关注的事件列表
* **WHEN** 趋势报告渲染为 Markdown，**THEN** 格式 **SHALL** 适合直接粘贴到企业内部报告或邮件中。

---

### 需求 4: 保持现有输出格式

**用户故事:** As a 系统用户，I want 趋势报告继续以 Markdown 格式输出，so that 我可以后续再决定是否升级为 HTML 或其他格式。

#### 验收标准

* **WHEN** pipeline 执行完成，**THEN** 系统 **SHALL** 输出 `{date_label}_trend_report.md` 文件。
* **WHEN** 报告输出，**THEN** 系统 **SHALL** 同时输出结构化的 JSON 数据（趋势+事件关联），方便后续渲染为其他格式。
